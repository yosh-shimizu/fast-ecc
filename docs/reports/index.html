fast-ecc — experiment reports

Measurements behind the changes in yosh-shimizu/fast-ecc. Written in Japanese.

warp 削減の解説landed

1 反復あたり 3 回の bilinear warp を 1 回に減らす仕組み。連鎖律で A⁻ᵀ を掛け戻すことで、勾配画像を別々に warp せずに済ませる。

warp 削減 × 境界修正、および gaussFiltSize の再最適化landed

二つの変更が無害に合成できるかの検証と、ぼかし幅の最適値の再検討。 warp 削減の利得が大窓で消える原因が OpenCV のスレッド化の非対称性であることを特定し、 単スレッドでは窓によらず 1.27〜1.31× で平坦であることを示す。 fast-ecc の「精度が良い」が gaussFiltSize=5 に依存した偶然だったことの確認も含む。

ガウス・ニュートン段の融合measured, not yet committed

ヤコビアンを実体化せず、ヘッセ行列と射影を 1 パスで作る。4 つの運動種別すべてで ヤコビアンが面分割積 u ⊗ w の列部分集合として書けることを示し、 節約がパラメータ数とともに増えることを実測する（窓 768・4 スレッドで homography 2.47×）。

これらのレポートは eval/ 以下の計測ハーネスを参照しているが、 それは fast-ecc とは別の作業ツリーにあり、このリポジトリには含まれていない。 数値の再現にはそのハーネスが要る。リポジトリ内で再現できるのは ./build/bench と ctest の範囲。

測定環境: Intel Core i7-8700K (6C/12T) / Windows 11 / MSVC / Release / OpenCV 4.15.0-dev（境界修正を適用したビルド）。
速度の数値には必ず運動種別・窓サイズ・スレッド数が付いている。この三つが揃わない比は意味を持たない。
